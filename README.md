
#Delivery Robot Navigation (Reinforcement Learning)


This repository contains a Python-based implementation of core Dynamic Programming algorithms used to solve Markov Decision Processes (MDPs) for autonomous robot pathfinding.

Algorithms Implemented:
-Policy Iteration
-Value Iteration (Synchronous & Asynchronous In-Place)
-Modified Policy Iteration 

Environment Highlights:
-Deterministic and stochastic (slippery) warehouse floor grids.
-Multi-dimensional state spaces evaluating the curse of dimensionality (pickup/delivery constraints).
